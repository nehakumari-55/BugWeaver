# Neha Kumari - GitHub Pages Portfolio

This package is ready for the repository that publishes:

`https://nehakumari-55.github.io/BugWeaver/`

## Publish

1. Open the `BugWeaver` repository on GitHub.
2. Back up or create a branch for the current version.
3. Upload every file and the `assets` folder from this package into the repository root.
4. Commit the changes to the branch configured in **Settings > Pages**.
5. Confirm that GitHub Pages deploys from the repository root.
6. Open the site URL and use a hard refresh after deployment.

## File structure

```text
BugWeaver/
  index.html
  styles.css
  styles-modern.css
  script.js
  Neha_Kumari_CV.pdf
  Neha_Kumari_CV.docx
  neha-kumari.png
```

All website links are relative, so the portfolio works correctly under the `/BugWeaver/` project path. File names are case-sensitive: upload the image exactly as `neha-kumari.png`. The migration case study intentionally anonymizes confidential client information.
